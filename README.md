# Судоку (Sudoku) — Лабораторная работа №2

Интерактивная браузерная игра «Судоку», разработанная на чистом JavaScript, HTML5 и CSS3.

🎮 **[Играть онлайн (GitHub Pages)](https://anhelm01.github.io/sudoku-yp2/)**

---

## 📋 Особенности

- **Генерация поля 9×9**: алгоритмическое построение базовой сетки со сдвигами и случайными перестановками строк/столбцов/блоков с сохранением корректности.
- **Уровни сложности**:
  - *Легкий* (~30 открытых ячеек)
  - *Средний* (~24 открытые ячейки)
  - *Сложный* (~18 открытых ячеек)
- **Управление**:
  - Мышь / сенсорный экран (клик по ячейкам, экранная цифровая панель)
  - Клавиатура: цифры `1`–`9`, `Backspace` / `Delete` для стирания, стрелки для навигации
- **Игровой процесс**:
  - Таймер прохождения
  - Счетчик ошибок и использованных подсказок
  - Подсветка активной строки, столбца, блока 3×3 и одинаковых цифр
  - Индикация конфликтующих ячеек
  - Таблица рекордов с сохранением лучшего времени в `localStorage`

---

## 🚀 Запуск локально

Проект не требует сборщиков или внешних зависимостей. Достаточно открыть `index.html` в любом современном браузере или запустить локальный сервер:

```bash
# Python
python3 -m http.server 8000

# или Node.js
npx serve .
```

---

## 📁 Структура проекта

- `index.html` — разметка игрового интерфейса и панели управления
- `style.css` — стили, адаптивная сетка, темы оформления ячеек и подсветки
- `script.js` — алгоритм генерации, валидации, игровой таймер и обработка событий
- `EXPLANATION.md` — подробный построчный и архитектурный разбор работы игры
